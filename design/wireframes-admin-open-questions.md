# Pertanyaan terbuka — wireframe admin

- Apakah laporan perlu ekspor Excel? PRD menaruhnya di luar MVP, jadi tombolnya belum digambar.
- Apakah pesanan yang belum dibayar perlu muncul di dashboard, atau cukup di daftar pesanan?
- Isi navigasi admin di ponsel: laci dari tombol menu, atau halaman terpisah? Tombol menunya sudah digambar, isinya belum.
- Apakah admin boleh mengubah isi pesanan yang sudah dibayar (PRD §9.2)? Kalau boleh, layar detail pesanan butuh mode ubah yang belum ada.
